# Éditeur de Texte Avancé

Un projet d'éditeur de texte avancé en PHP et HTML, inspiré de OnlyOffice.

## Fonctionnalités
- Création, ouverture et sauvegarde de documents
- Mise en forme du texte (gras, italique, etc.)
- Gestion des fichiers

## Installation
1. Cloner le dépôt
2. Configurer la base de données dans `config.php`
3. Lancer un serveur web (ex: Apache) et accéder à `index.php`

## Structure du projet
- `index.php` : Page principale
- `config.php` : Configuration
- `editor.php` : Logique d'édition
- `save.php` : Logique de sauvegarde
- `/public` : Fichiers statiques (CSS, JS)
- `/documents` : Stockage des documents
